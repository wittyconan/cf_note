# 云笔记 Pro - 产品需求文档

## 1. 产品概述

基于 Cloudflare Workers + D1 的轻量级云笔记应用，对标有道云笔记的单用户版本。
- 解决笔记记录、分类管理、富文本编辑需求
- 支持移动端 PWA，可作为 App 使用
- 目标：极致的加载速度和流畅体验

## 2. 核心功能

### 2.1 用户认证
- 简洁的登录界面
- 记住登录状态（localStorage）
- 支持多账号切换

### 2.2 笔记管理
- 创建/编辑/删除笔记
- 笔记分类管理
- 拖拽排序
- 收藏/置顶笔记
- 搜索笔记
- 笔记预览和快速查看

### 2.3 富文本编辑
- Quill 编辑器
- 支持文字格式化
- 支持链接、图片
- 自动保存草稿

### 2.4 移动端优化
- PWA 支持（可添加到主屏幕）
- 触摸友好
- 响应式布局
- 离线访问

## 3. UI/UX 设计

### 3.1 设计风格
- 简约现代风格
- 圆角卡片设计
- 柔和阴影
- 主色调：靛蓝色渐变 (#4f46e5 → #7c3aed)
- 背景：浅灰白 (#f8fafc)
- 文字：深灰 (#1f2937)

### 3.2 响应式布局
- 移动端：单列卡片
- 平板：双列卡片
- 桌面：三列卡片
- 全屏编辑器

## 4. 技术架构

### 4.1 前端
- HTML5 + Tailwind CSS
- Quill 富文本编辑器
- SortableJS 拖拽
- PWA (Service Worker)

### 4.2 后端
- Cloudflare Workers
- D1 数据库
- 单文件部署

### 4.3 数据库设计
- users 表：用户信息
- categories 表：分类
- notes 表：笔记（含 category, sort_order, is_pinned, is_favorite）
